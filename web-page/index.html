Windows PowerToys & Clipboard History for Linux

Missing your favourite Windows 11 productivity tools on Linux? MagicToys brings the exact hotkeys and native power directly to your desktop.

Win + V Equivalent

Clipboard History

Hotkey: Alt + V

Recall previously copied text, rich formatted text, and decoded PNG images. Smart de-duplication keeps your history clean while SQLite stores items locally.

Win + . Equivalent

Emoji & Symbol Picker

Hotkey: Alt + .

Full Unicode emoji grid picker with category tabs, live search, and automatic LRU frequency tracking so your most used emojis appear at the top.

PowerToys OCR Equivalent

Screen Text Extractor (OCR)

Hotkey: Alt + Shift + T

Drag a box over any screen area to grab text from images, non-copyable PDFs, or video frames directly into your clipboard using Tesseract OCR.

Frequently Asked Questions

What is Ople MagicToys for Linux?

Ople MagicToys for Linux is a free, open-source desktop utility suite that brings popular Windows PowerToys and Windows 11 features to Linux. It includes Clipboard History (Alt+V), an Emoji Picker (Alt+.), and a Screen Text Extractor OCR (Alt+Shift+T).

Is MagicToys a Windows PowerToys alternative for Linux?

Yes! MagicToys is designed specifically as a Linux equivalent to Windows PowerToys and Windows 11 Clipboard History (Win+V). It brings Win+V clipboard history, Win+. emoji picker, and PowerToys Text Extractor (OCR) natively to Ubuntu, Debian, Arch Linux, Fedora, and other Linux distributions.

How do I install MagicToys on Linux?

Run this single command in your terminal: curl -sS https://magictoys.ople.in/install.sh | bash. It automatically detects your Linux distribution, downloads the matching pre-built package (.deb, .pkg.tar.zst, .rpm, or AppImage), configures udev permissions, and sets up desktop shortcuts automatically.

Does it work on Wayland (GNOME, KDE)?

Yes. MagicToys uses a /dev/uinput virtual keyboard device to inject paste keystrokes on Wayland compositors. It has been tested and confirmed working on GNOME Wayland (Ubuntu), KDE Plasma Wayland, XFCE, and Arch Linux.

Is MagicToys free and open source?

Yes, completely. MagicToys is released under the MIT License by Ople. All source code lives on GitHub. Contributions, bug reports, and pull requests are actively welcome.

Is my clipboard data private?

Yes. Every clipboard item stays completely local. Data is written to an SQLite database at ~/.config/magictoys/db.db. There is zero telemetry, zero analytics, and zero network requests by the application.
